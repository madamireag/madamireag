# Madalina Mireag

Software Developer at **Siemens Energy** in Bucharest, working on a global team 
building TMS - an industrial software for managing oil & gas distribution terminals.

Before Siemens, I worked at **TotalSoft** on Charisma ERP, across modules covering 
transport compliance, lease management, and travel expense processing.

My day-to-day is mostly C# and .NET - desktop applications in WPF, REST APIs in 
ASP.NET Core, and some Angular on the frontend side.
